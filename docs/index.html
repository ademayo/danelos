Artix + Hyprland Desktop Recipe

One command from the Artix ISO to a complete tiling desktop. dinit as init, Hyprland as the compositor, Arc Dark gluing it together. What you end up with reads as a hand-configured Artix install.

Artix Linux dinit init Hyprland Wayland Arc Dark theme SDDM Arc Dark zsh + agnoster

The Stack

◆ Base

Artix Linux, dinit init, elogind, userspawn for user session spawning.

▣ Compositor

Hyprland with hypridle, hyprlock, hyprpaper, hyprshot — native Wayland throughout.

⏻ Login

SDDM greeter on Wayland (Weston kiosk), bundled Arc Dark QML theme. No X server anywhere in the boot path.

⌘ Shell

zsh as default with an agnoster prompt, autosuggestions and syntax highlighting. dash as /bin/sh.

▤ Terminal

ghostty, Arc Dark palette, CaskaydiaCove Nerd Font. Bound to Ctrl+Alt+T and Super+Return.

◫ Desktop

quickshell (bar + launcher), wlogout, thunar + tumbler thumbnails. Arc Dark GTK + Papirus icons across GTK and Qt.

✦ Everyday Apps

ristretto (images), mpv (video), qpdfview (PDFs), galculator, xarchiver, pavucontrol-qt (sound) — lightweight XFCE/MATE/Qt picks, no GNOME apps.

Install

Runs from a stock artix-base-dinit ISO. Boot it, log in as the live user (password artix), connect to Wi-Fi or Ethernet, then:

live session 
# wipes the target disk — the installer asks before touching anything
sudo pacman -Syu git --noconfirm && \
  git clone https://github.com/ademayo/danelos.git && \
  sudo ./danelos/installer/recipe

Wi-Fi via wpa_supplicant

The stock ISO ships no NetworkManager — bring the link up by hand first (as root, wlan0 = your interface, see ip link):

live session 
rfkill unblock all
wpa_supplicant -B -i wlan0 -c <(wpa_passphrase 'MyNetwork' 'MyPassword')
dhcpcd wlan0

Once ping -c1 artixlinux.org works, run the installer. It asks for hostname, your name, username, passwords and timezone, then partitions the disk as EFI + swap + Btrfs root (@ and @home subvolumes, zstd compression), pacstraps Artix + dinit, installs the desktop, creates your user and sets up GRUB. Reboot into Hyprland.
